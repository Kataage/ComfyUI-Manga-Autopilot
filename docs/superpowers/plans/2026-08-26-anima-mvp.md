# Anima Manga Autopilot MVP Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Goal: Extend the existing Manga Autopilot with a backward-compatible Anima MVP that plans with LM Studio structured output, maintains story and scene continuity, generates deterministic Anima prompts, pauses at review gates, snapshots every run, and resumes safely.

Architecture: Keep the current generic planner, workflow registry, generation loop, renderer, export service, and existing project format working. Add Anima behavior behind `generation.profile_id` and `review_policy`; new focused domain services own semantic validation, continuity reduction, profile resolution, preflight, snapshots, and invalidation. The default legacy path preserves current auto-completion while new Anima projects use strict validation and review gates.

Tech Stack: Python 3.10+, Pydantic 2, jsonschema 4, aiohttp 3.9, Pillow 10, pytest, ruff, ComfyUI API workflows, LM Studio OpenAI-compatible `/v1/chat/completions`.

## Global Constraints

- Extend the official `Kataage/ComfyUI-Manga-Autopilot` code; do not replace existing subsystems.
- Work only on branch `codex/anima-mvp` in the isolated clone.
- Preserve old project loading and old generic workflow behavior.
- New Anima projects default to Story, Storyboard, and Artwork review gates.
- No image generation occurs before Storyboard approval.
- Use Qwen3.5-9B as the MVP live acceptance model; do not download or load it automatically.
- Use `anima_turbo` for the live image acceptance path; base and aesthetic receive profile and mock coverage.
- Do not download, bundle, move, or overwrite model files or installed ComfyUI workflows.
- Keep normal tests GPU-free. Live LM Studio, one-panel, and four-page GPU tests remain opt-in and approval-gated.
- Store complete prompts in run snapshots, prompt hashes in diagnostic logs, and no credentials in either.
- Persist one panel before queueing the next. Resume skips completed panels.
- Apply TDD to each production behavior: write a failing test, run it, add the smallest implementation, rerun.
