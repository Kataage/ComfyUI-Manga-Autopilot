# v0.1.0-rc1 Release Notes

**Release date:** 2026-06-12

## Highlights

First release candidate of Manga Autopilot — an AI-assisted manga
creation pipeline that generates panel images from page descriptions
using ComfyUI workflows.

## What Works

- **1-page Autopilot**: Generate a single page from text description
- **2-page / 4-page Autopilot**: Multi-page generation
- **Multi-panel pages**: Configurable panel count per page
- **4 pages x 2 panels**: Production-scale test scenario
- **Project management**: Create, export, re-import, re-edit projects
- **Panel editing**: Modify individual panels with new prompts

## Remote / Modal Execution

- **RemoteHTTPExecutor**: Execute panels on remote GPU workers
- **Async polling**: Non-blocking job status checks
- **Remote cancel**: Cancel running remote jobs
- **Artifact URL / path**: Remote workers can return URLs or paths
- **Modal Worker MVP**: Basic Modal GPU worker for panel generation
- **Modal ComfyUI execution**: Execute ComfyUI workflows on Modal (opt-in)
- **Modal preflight validation**: Validate env, paths, checkpoints, workflows
- **Modal Volume setup**: Helper for uploading models to Modal Volume
- **Modal worker hardening**: Auth, timeouts, concurrency, diagnostics

## Artifact Storage

- **ArtifactStore Protocol**: Unified interface for local and S3 storage
- **LocalArtifactStore**: File-based storage for CI
- **S3CompatibleArtifactStore**: AWS S3 / Cloudflare R2 support
- **Signed URL support**: Public, private, and signed URL modes
- **Artifact access policy**: Configurable URL generation and TTL

## Run History / Resume

- **Run history**: Per-project run tracking with timestamps
- **Per-run artifacts**: Isolated artifact directories per run
- **Run cleanup**: Configurable cleanup policy for old runs
- **Failure resume**: Resume interrupted autopilot runs
- **Cancelled restart**: Restart cancelled projects from scratch
- **Cancelled partial resume**: Resume cancelled projects (skip completed panels)

## Exports

- **PNG export**: Panel images with metadata
- **Webtoon export**: Long-strip format for webtoon platforms
- **PDF export**: Panel layout PDF
- **ZIP export**: Bundled project files

## Tests

- **791 passed**, 15 skipped (opt-in E2E)
- **6 release gate tests** for critical paths
- Contract tests for all Modal workers and artifact stores
- Opt-in E2E tests for real ComfyUI, Modal, and S3/R2

## Opt-in Integrations

- `MANGA_AUTOPILOT_REAL_COMFYUI_E2E=1` — real ComfyUI generation
- `MANGA_AUTOPILOT_REAL_MODAL_E2E=1` — real Modal GPU
- `MANGA_AUTOPILOT_REAL_MODAL_COMFYUI_E2E=1` — real Modal ComfyUI
- `MANGA_AUTOPILOT_REAL_S3_E2E=1` — real S3/R2 storage

## Known Limitations

- Standard CI never runs Real ComfyUI, Modal, or S3/R2
- Modal ComfyUI is opt-in only
- No automatic checkpoint downloads
- Model license responsibility is on the user
- S3/R2 bucket creation is not automated
- Full user auth is not implemented
- Image similarity QA is not implemented
- Production autoscaling is not implemented
- Signed URL revocation is not implemented

See `docs/release/v0.1.0-rc1_known_limitations.md` for full details.

## Upgrade / Install Notes

```bash
pip install -e ".[modal]"   # Modal support (optional)
pip install -e ".[s3]"      # S3/R2 support (optional)
```

Place licensed model files on Modal Volume or local ComfyUI installation.
No automatic model downloads are performed.
