# v0.1.0-rc1 Environment Variable Inventory

Complete list of environment variables for Manga Autopilot.

## Remote Executor

| Name | Default | Required | Scope | Description |
|------|---------|----------|-------|-------------|
| `MANGA_AUTOPILOT_REMOTE_WORKER_URL` | (none) | No | Autopilot → remote | URL of the remote worker endpoint |
| `MANGA_AUTOPILOT_REMOTE_WORKER_TOKEN` | (none) | No | Autopilot → remote | Bearer token for remote worker auth |

## Modal Worker (MVP)

| Name | Default | Required | Scope | Description |
|------|---------|----------|-------|-------------|
| `MANGA_AUTOPILOT_MODAL_WORKER_TOKEN` | (empty) | No | Modal worker auth | Bearer token for worker endpoints |
| `MANGA_AUTOPILOT_MODAL_HEALTH_REQUIRES_AUTH` | `false` | No | Modal worker auth | Require auth for /v1/health |
| `MANGA_AUTOPILOT_MODAL_STARTUP_TIMEOUT_SEC` | `120` | No | Modal worker | ComfyUI startup timeout |
| `MANGA_AUTOPILOT_MODAL_GENERATION_TIMEOUT_SEC` | `600` | No | Modal worker | Generation timeout |
| `MANGA_AUTOPILOT_MODAL_UPLOAD_TIMEOUT_SEC` | `120` | No | Modal worker | Artifact upload timeout |
| `MANGA_AUTOPILOT_MODAL_JOB_TTL_SEC` | `3600` | No | Modal worker | Async job TTL |
| `MANGA_AUTOPILOT_MODAL_MAX_CONCURRENT_JOBS` | `1` | No | Modal worker | Max concurrent async jobs |
| `MANGA_AUTOPILOT_MODAL_REJECT_WHEN_BUSY` | `true` | No | Modal worker | Reject when at concurrency limit |
